# Saiyai Dashboard

ระบบรายงานประจำวันสำหรับงานติดตั้งและซ่อมแซมสายเคเบิล (สายใย)

## ฟีเจอร์
- ฟอร์มรายงานประจำวัน ครบ 9 หัวข้อ (รหัสงาน, ชื่องาน, หัวต่อ, พาดสายใหม่, ร่นสาย, จุดตัดต่อ, รื้อสายกลับ, รายละเอียด, ภาพงาน)
- เพิ่ม/ลบ หัวต่อและรายการสายได้ตามจริง
- แนบรูปได้หลายรูป (ถ่ายจากกล้องหรือเลือกจากเครื่อง)
- บันทึกและดูรายงานย้อนหลัง พร้อมสรุปยอดและพิมพ์ / บันทึก PDF

## การใช้งาน
เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages

## หมายเหตุ
ข้อมูลและรูปจัดเก็บในเบราว์เซอร์ของแต่ละเครื่อง (localStorage) — ยังไม่ได้ sync ข้ามเครื่อง
หากต้องการให้หลายคนใช้ข้อมูลร่วมกัน ต้องต่อฐานข้อมูลจริงในขั้นถัดไป
